SECTION 1 — FOUNDATIONAL TOPOLOGY AND MANIFOLD INITIALIZATION
--------------------------------------------------------------------------------

COMPONENT: Node
CLASS NAME: Node
FILE LOCATION: resonance_engine.py

You must initialize every node as a high-dimensional bipolar vector. The default
dimensionality is 10,000. Bipolar means every element is strictly +1 or -1,
generated by random uniform draw.

MEMORY CONSTRAINT — MANDATORY:
To prevent catastrophic memory bottlenecks when scaling this system for edge
devices, do not store node vectors as floating-point arrays in standard RAM.
You must compress each bipolar vector to a packed bitset immediately on creation
using numpy.packbits. Convert the raw ±1 array to 0/1 integers before packing.
Unpack the bitset back into float32 format ONLY when the vector is actively
needed for similarity computation. Implement this as a property getter named
`vector` so callers use the same interface regardless of storage format.

Node fields required:
idx : int — unique integer identifier
dim : int — vector dimensionality (default 10,000)
_packed : np.ndarray — compressed bitset storage (do not expose directly)
activation : float — current activation level, initialized to 0.0
ema : float — short-term exponential moving average of activation
is_root : bool — True only for node 0
cluster_id : int | None — semantic cluster assignment (assigned externally)

vector property (read-only):
Unpack _packed, slice to self.dim, cast to float32, convert 0→-1 and 1→+1.
Return shape (dim,) float32 array. This is the only path to the raw vector.

4. Call _build_adjacency() — see below.

6. Set self.tick = 0 and self.locked = False.

ADJACENCY LISTS — MANDATORY:
Method: _build_adjacency(self)

You must build adjacency lookup dictionaries the exact moment the graph
initializes. Create two structures:
self.adj_in : dict[int, list[Edge]] — maps node idx to all its incoming edges
self.adj_out : dict[int, list[Edge]] — maps node idx to all its outgoing edges

Populate both by iterating self.edges once. Use collections.defaultdict(list).

You will use these lookup tables exclusively during the propagation and learning
loops. You will never iterate self.edges directly during a hot tick. Rebuild
these structures ONLY when the topology undergoes a physical pruning or growth
event (node insertion, edge deletion, hard reset). Call _build_adjacency() again
after any such event.

Constants (define at module level):

SECTION 2 — THE SIMILARITY INDEX (REPLACING BRUTE-FORCE ATTENTION)
--------------------------------------------------------------------------------

COMPONENT: ResonanceGraph — Similarity Index
METHOD NAMES: _build_sim_index, _query_neighbors, _maybe_reindex

Library: faiss (import faiss). Use IndexFlatIP (inner product index).

Method: _build_sim_index(self)
Stack all node vectors into a float32 matrix of shape (n_nodes, dim).
Initialize a faiss.IndexFlatIP(self.dim) index.
Normalize all vectors to unit length before adding (IMPORTANT: IndexFlatIP
computes inner product, which equals cosine similarity only on unit vectors).
Add the normalized matrix to the index.
Store as self.sim_index.

Method: _query_neighbors(self, node_idx: int) -> list[int]
Retrieve the vector for the given node via the property getter.
Normalize it to unit length.
Query self.sim_index for top (self.top_k + 1) results.
Remove the query node itself from results (it always appears as its own
nearest neighbor with similarity 1.0).
Return the list of up to top_k neighbor indices.

Method: _maybe_reindex(self)
Called at the top of every propagate() call.
If self.tick % self.reindex_interval == 0, call _build_sim_index() to
rebuild the index with current node vectors. This reflects any vector drift
from long-term learning. Do not call this more frequently — it is expensive.

SECTION 3 — THE RESONANCE ENGINE (WAVE PROPAGATION)
--------------------------------------------------------------------------------

COMPONENT: ResonanceGraph — Propagation
METHOD NAME: propagate(self, dt: float = 0.001)

This method is the core forward pass. It replaces transformer attention with
physical kinetic resonance. It runs one time step of the damped wave equation.

Step-by-step implementation:

1. GUARD: If self.locked is True, return immediately. Do nothing.

2. ROOT RESET (NON-NEGOTIABLE):
Before any other computation, set self.nodes[0].activation = 1.0.
This is the first line executed after the lock check.
Enforce root edge floors: for every edge in self.root_edges, set
tension = max(ROOT_TENSION_FLOOR, edge.tension).

3. REINDEX CHECK: Call self._maybe_reindex().

4. BUILD INCOMING SIGNAL ARRAY:
For each non-root node, compute the incoming resonance signal using only
the node's approximate nearest neighbors (from _query_neighbors). Do NOT
compute similarity across all nodes.

For each neighbor j in the neighborhood of node i:
sim(i, j) = dot product of normalized vectors for i and j
(approximate cosine similarity)
signal_contribution = edge_tension(j→i) × nodes[j].activation × max(0, sim)

Sum all contributions: incoming_signal[i] = Σ contributions

5. COMPUTE DERIVATIVES:
Define a function dA(activations: np.ndarray) -> np.ndarray that returns
the time derivative for each node:
dA[0] = 0 (root is locked, skip)
dA[i] = -damping × activations[i] + incoming_signal[i]

6. HEUN CORRECTOR INTEGRATION (MANDATORY — DO NOT USE EULER):
This is a second-order Runge-Kutta corrector. A plain Euler step will
cause the tension matrix to overshoot and the activations will diverge
to infinity under high-tension conditions. This is not optional.

A = np.array([n.activation for n in self.nodes])
k1 = dA(A)
A_pred = np.clip(A + dt * k1, 0.0, 1.0)
k2 = dA(A_pred)
A_next = np.clip(A + 0.5 * dt * (k1 + k2), 0.0, 1.0)
A_next[0] = 1.0 (re-lock root after integration)

7. WRITE BACK: Update node.activation for every node from A_next.

8. INCREMENT: self.tick += 1

SECTION 4 — THE MYCELIUM LEARNING LOOP (REPLACING BACKPROPAGATION)
--------------------------------------------------------------------------------

COMPONENT: ResonanceGraph — Root Initialization
METHOD NAME: _init_root(self)

Set nodes[0].is_root = True.
Set nodes[0].activation = 1.0.
Set the root vector to all +1 (identity frequency): unpack, set all to 1,
re-pack and store as nodes[0]._packed.
Identify all edges with src == 0. Store as self.root_edges (list[Edge]).
Set edge.read_only = True on every edge in self.root_edges.
Set edge.tension = max(ROOT_TENSION_FLOOR, edge.tension) on each.


COMPONENT: ResonanceGraph — Local Learning
METHOD NAME: local_learn(self)

GUARD: If self.locked is True, return immediately.

This method eliminates backpropagation by executing Oja's rule locally at
every node. It must be called once per tick, immediately after propagate().

CRITICAL — SYNCHRONOUS UPDATE RULE:
You must NOT apply tension changes as you iterate. Asynchronous in-loop
updates cause massive oscillation because each node's Oja update sees
already-modified weights from earlier nodes in the same tick. This will
destabilize the learning process. You will accumulate every mathematical
delta into a centralized staging buffer (a dict keyed by Edge object) during
the full node scan. Apply all weight changes simultaneously in a second pass
at the very end of the method.

Step-by-step implementation:

1. Initialize: deltas = defaultdict(float)

2. For each non-root node nd in self.nodes:
a. Update EMA: nd.ema = 0.95 × nd.ema + 0.05 × nd.activation
b. Compute friction: friction = |nd.activation - nd.ema|
c. If friction < 0.05: continue (no mismatch, no learning)
d. For each incoming edge e in self.adj_in[nd.idx]:
- If e.read_only: skip (root edges are protected)
- src_act = nodes[e.src].activation
- If src_act < 0.05: skip (source not meaningfully active)
- Oja delta: Δ = η × (nd.activation × src_act − nd.activation² × e.tension)
- Accumulate: deltas[e] += Δ

3. APPLY ALL DELTAS SIMULTANEOUSLY:
For each (edge, delta) in deltas.items():
edge.tension = np.clip(edge.tension + delta, MIN_TENSION, 1.0)

4. THERMODYNAMIC NORMALIZATION — MANDATORY:
After applying all deltas, normalize incoming tensions for every non-root
node so that the total energy entering each node sums to 1.0.
This prevents runaway feedback amplification.

For each non-root node nd:
total = sum of edge.tension for all edges in self.adj_in[nd.idx]
EPSILON GUARD: if total <= EPS, skip this node entirely (dormant node —
do not attempt division, leave tensions at their current floor values)
If total > EPS:
for each edge in self.adj_in[nd.idx]:
edge.tension = max(MIN_TENSION, edge.tension / total)

SECTION 5 — THE CRYPTOGRAPHIC ANCHOR AND OVERRIDE
--------------------------------------------------------------------------------

COMPONENT: OverrideInterceptor
CLASS NAME: OverrideInterceptor
FILE LOCATION: resonance_engine.py

Library: cryptography.hazmat.primitives.asymmetric.ed25519

Constructor parameters:
public_key_bytes : bytes — 32-byte Ed25519 public key
graph : ResonanceGraph — reference to the live engine

Internal state:
self._seen_nonces : set[str] — rolling ledger of recently verified sig hashes

Method: check_input(self, data: bytes) -> bool

This method intercepts the input pipeline before any data reaches the wave
simulation. Call this method on every external input before calling propagate().

The expected format of `data` is:
command_bytes (variable length) + timestamp_bytes (8 bytes, big-endian uint64)
+ signature_bytes (64 bytes, Ed25519 signature over the preceding bytes)

Total minimum length: 8 + 64 = 72 bytes (no command). Reject if shorter.

Step-by-step:
1. Split: payload = data[:-64], signature = data[-64:]
2. Verify Ed25519 signature over payload using self.pubkey.
If verification fails: return False.
3. Extract timestamp: ts = struct.unpack(">Q", payload[-8:])[0]
4. REPLAY GUARD — TIME WINDOW:
If abs(time.time() - ts) > 30: return False (command expired or from future)
5. REPLAY GUARD — NONCE LEDGER:
sig_hash = hashlib.sha256(signature).hexdigest()
If sig_hash in self._seen_nonces: return False (duplicate broadcast)
Add sig_hash to self._seen_nonces.
(Optional: prune nonces older than 60 seconds to prevent unbounded growth)
6. Call self._execute_override().
7. Return True.

Method: _execute_override(self)

This is the absolute damping field. Upon verified authorization:
1. Set self.graph.damping = 1.0
2. For every node in self.graph.nodes that is NOT the root:
node.activation = 0.0
node.ema = 0.0
3. Set self.graph.locked = True
4. Print or log: "[OVERRIDE] Absolute damping field engaged. Engine locked."

The graph remains locked until an external caller sets graph.locked = False
and graph.damping back to its operational value. The override does not
automatically restart the engine.

Helper: sign_command(command: bytes, privkey) -> bytes
This is a standalone module-level function for the key holder to generate
valid override commands.
payload = command + struct.pack(">Q", int(time.time()))
signature = privkey.sign(payload)
return payload + signature
